# Output Documentation

This folder contains all output files generated by the analysis scripts.

## Folder Structure

```
output/
├── figures/     # Publication-ready figures (PDF)
├── tables/      # LaTeX tables (.tex)
├── csv/         # Data tables (CSV format)
└── rds/         # R data objects (for intermediate results)
```
