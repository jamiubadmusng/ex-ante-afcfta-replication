# Data Documentation

This folder contains the data files used in the analysis. Due to size constraints, some raw data files may need to be downloaded separately from their original sources.

## Data Sources

### 1. International Trade and Production Database for Estimation (ITPD-E-R02)

**Source:** U.S. International Trade Commission  
**URL:** https://www.usitc.gov/data/gravity/itpde.htm  
**License:** Public Domain  

The ITPD-E-R02 provides consistent bilateral trade and domestic trade data for 265 countries, 170 industries, and the years 1986–2019.

**Files:**
- `itpder2.rds` — Aggregated trade data (all sectors combined)
- `itpder2_1.rds` to `itpder2_170.rds` — Industry-level trade data (one file per industry)

### 2. Dynamic Gravity Dataset (DGD, Release 2.1)

**Source:** U.S. International Trade Commission  
**URL:** https://www.usitc.gov/data/gravity/dgd.htm  
**License:** Public Domain  

The DGD provides gravity covariates including bilateral distance, contiguity, colonial history, common language, and trade agreement membership.

**Files:**
- `dgd_2_1.rds` — Gravity covariates for main analysis (2000–2019)
- `dgd_2_1_rob.rds` — Extended gravity covariates for robustness checks (includes WTO, PTA, EIA)
- `release_2.1_2000_2019.zip` — Raw DGD data files

### 3. Structural Gravity Database

**Source:** World Trade Organization  
**URL:** https://www.wto.org/english/res_e/reser_e/structural_gravity_e.htm  
**License:** Public Domain  

Manufacturing trade data used for robustness checks.

**Files:**
- `struc.rds` — Processed Structural Gravity data
- `struc_2016_balanced.dta` — Balanced panel for GE analysis

## Variables

### Trade Data (ITPD-E-R02)

| Variable | Description |
|----------|-------------|
| `exporter` | ISO-3 code of exporting country |
| `importer` | ISO-3 code of importing country |
| `year` | Year (2000–2019) |
| `trade` | Bilateral trade value (current USD, millions) |
| `industry_id` | Industry identifier (1–170) |
| `broad_sector` | Sector classification (Agriculture, Manufacturing, Mining and Energy, Services) |

### Gravity Covariates (DGD)

| Variable | Description |
|----------|-------------|
| `dist` | Log of bilateral distance (km) |
| `cntg` | Contiguity indicator (1 = share border) |
| `col` | Colonial relationship indicator |
| `lang` | Common official language indicator |
| `rta` | Regional Trade Agreement indicator |
| `wto` | WTO membership indicator |
| `pta` | Preferential Trade Agreement indicator |
| `eia` | Economic Integration Agreement indicator |

### Border Variables (Constructed)

| Variable | Description |
|----------|-------------|
| `afcfta_brdr` | Intra-AfCFTA international trade indicator |
| `afcfta_row_brdr` | AfCFTA-to-Rest of World trade indicator |
| `row_to_row` | Rest of World international trade indicator |

## Downloading Raw Data

If you need to download the raw data files:

1. **ITPD-E-R02:** Visit https://www.usitc.gov/data/gravity/itpde.htm and download the industry-level CSV files
2. **DGD:** Visit https://www.usitc.gov/data/gravity/dgd.htm and download Release 2.1
3. **Structural Gravity:** Visit https://www.wto.org/english/res_e/reser_e/structural_gravity_e.htm

Place downloaded files in this folder and run `code/01_clean_industry_data.R` to process them.
